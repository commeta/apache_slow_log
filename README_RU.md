# Apache Slow Request Analyzer

[English](README.md)

Этот скрипт анализирует логи Apache, чтобы выявить самые медленные запросы к серверу. Он извлекает информацию о запросах из конфигурационных файлов, находит соответствующие логи и создает список 100 самых медленных запросов на основе времени ответа сервера, записанного в микросекундах.

## Особенности

- **Современная архитектура**: Построен на Python 3.8+ с использованием dataclasses, type hints и современных библиотек
- **Надежная обработка ошибок**: Всесторонняя обработка ошибок и логирование
- **Несколько форматов вывода**: Поддержка текстового, JSON и CSV форматов вывода
- **Настраиваемый**: Конфигурация на основе JSON с возможностью переопределения из командной строки
- **Эффективное использование памяти**: Потоковая обработка для больших файлов логов
- **Поддержка сжатых логов**: Обрабатывает gzip и bzip2 сжатые файлы логов
- **Гибкий парсинг логов**: Поддержка различных форматов логов Apache
- **Статистика**: Детальная статистика обработки
- **Безопасность**: Использует subprocess вместо os.popen для команд shell

## Функциональность

1. **Обнаружение логов**: Ищет все конфигурационные файлы Apache, содержащие директиву CustomLog, чтобы определить расположение файлов логов
2. **Парсинг логов**: Анализирует каждую строку лога для извлечения IP-адреса и времени выполнения запроса
3. **Извлечение домена**: Извлекает домен из пути к файлу лога с использованием гибких шаблонов
4. **Поиск топовых запросов**: Собирает данные запросов и поддерживает только 100 самых медленных с помощью heapq для эффективного управления памятью
5. **Слияние данных**: Сравнивает новые данные с существующими записями slow.log, обновляя записи, если новые запросы медленнее
6. **Запись вывода**: Сохраняет результаты в различных форматах (текст, JSON, CSV)

## Установка и использование

### Требования

- Python 3.8 или выше
- Доступ к логам Apache
- Модули стандартной библиотеки (без внешних зависимостей)

### Установка

1. Скопируйте скрипт на ваш сервер:
```bash
wget https://raw.githubusercontent.com/commeta/apache_slow_log/main/apache_slow_log.py
chmod +x apache_slow_log.py
```

2. Необязательно: создайте конфигурационный файл:
```bash
cp config.json.example config.json
```

### Базовое использование

```bash
# Базовое использование с настройками по умолчанию
python3 apache_slow_log.py

# С пользовательской конфигурацией
python3 apache_slow_log.py --config config.json

# С параметрами командной строки
python3 apache_slow_log.py --top-n 50 --output-format json --verbose

# Установить порог минимальной длительности (в микросекундах)
python3 apache_slow_log.py --min-duration 500000  # 0.5 секунд
```

### Параметры конфигурации

Создайте файл `config.json`:

```json
{
  "log_files_glob": "/etc/apache2/sites-enabled/*/*.conf",
  "slow_log_path": "/var/log/apache2/slow.log",
  "top_n": 100,
  "min_duration": 100000,
  "log_format": "combined",
  "output_format": "text",
  "include_stats": true
}
```

**Параметры конфигурации:**

- `log_files_glob`: Шаблон для поиска конфигурационных файлов Apache
- `slow_log_path`: Путь к файлу вывода
- `top_n`: Количество отслеживаемых самых медленных запросов
- `min_duration`: Минимальная длительность запроса в микросекундах для учета
- `log_format`: Формат лога Apache (`combined`, `common`, или `custom`)
- `output_format`: Формат вывода (`text`, `json`, или `csv`)
- `include_stats`: Включать ли статистику обработки

## Формат времени

Время выполнения запроса записывается в микросекундах. Чтобы преобразовать это значение в секунды, используйте:

**Время (в секундах) = Время (в микросекундах) / 1,000,000**

## Конфигурация формата лога Apache

Скрипт работает с логами Apache, которые включают параметр `%D` в директиве LogFormat:

```apache
LogFormat "%a %l %u %t \"%r\" %>s %b \"%{Referer}i\" \"%{User-Agent}i\" %D" combined
```

**Ключевые параметры:**
- `%a`: IP-адрес клиента
- `%l`: Логин клиента (обычно -)
- `%u`: Имя пользователя (если используется аутентификация)
- `%t`: Время запроса
- `%r`: Строка запроса (например, GET /index.html HTTP/1.1)
- `%>s`: Код статуса HTTP
- `%b`: Размер ответа в байтах
- `%{Referer}i`: Заголовок Referer
- `%{User-Agent}i`: Заголовок User-Agent
- `%D`: Время обработки запроса в микросекундах

## Расширенные возможности

### Пользовательские шаблоны логов

Для нестандартных форматов логов можно указать собственный шаблон регулярного выражения:

```json
{
  "log_format": "custom",
  "custom_pattern": "^(\\S+) .* (\\d+)$"
}
```

### Поддержка сжатых логов

Скрипт автоматически обрабатывает сжатые файлы логов:
- `.gz` файлы (gzip)
- `.bz2` файлы (bzip2)

### Обработка ошибок

Скрипт включает всестороннюю обработку ошибок:
- Ошибки доступа к файлам
- Ошибки парсинга логов
- Ошибки конфигурации
- Управление памятью

## Соображения по производительности

- **Использование памяти**: Использует потоковую обработку для эффективной работы с большими файлами логов
- **Скорость обработки**: Оптимизирован с помощью heap-based top-N выбора
- **Дисковый ввод-вывод**: Минимальные операции с диском благодаря буферизированному чтению
- **Масштабируемость**: Может обработать миллионы записей логов

## Параметры командной строки

```bash
python3 apache_slow_log.py --help
```

**Доступные параметры:**
- `--config`, `-c`: Путь к JSON конфигурационному файлу
- `--verbose`, `-v`: Включить подробное логирование
- `--top-n`, `-n`: Количество отслеживаемых топовых запросов
- `--output-format`, `-f`: Формат вывода (text, json, csv)
- `--min-duration`, `-d`: Порог минимальной длительности в микросекундах

## Мониторинг и автоматизация

### Пример задания cron

```bash
# Запуск каждый час
0 * * * * /usr/bin/python3 /path/to/apache_slow_log.py --config /path/to/config.json

# Запуск ежедневно с уведомлением по email
0 2 * * * /usr/bin/python3 /path/to/apache_slow_log.py --verbose 2>&1 | mail -s "Apache Slow Log Analysis" admin@example.com
```

### Ротация логов

Скрипт работает с системами ротации логов. Настройте logrotate для сохранения временных меток:

```bash
/var/log/apache2/*.log {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
    postrotate
        /usr/bin/python3 /path/to/apache_slow_log.py --config /path/to/config.json
    endscript
}
```

## Устранение неисправностей

### Частые проблемы

1. **Permission Denied**: Убедитесь, что скрипт имеет права чтения файлов логов
2. **No Log Files Found**: Проверьте шаблон `log_files_glob`
3. **Parsing Errors**: Убедитесь, что формат вашего лога соответствует ожидаемому шаблону
4. **Memory Issues**: Увеличьте `min_duration`, чтобы отфильтровать быстрые запросы

### Режим отладки

Запустите с подробным логированием для диагностики проблем:

```bash
python3 apache_slow_log.py --verbose
```
